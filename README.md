# Roblox

Repositorio de notas, scripts y recursos relacionados con Roblox. El contenido es heterogéneo y se conserva como material de exploración; no representa un SDK ni una aplicación única.

Antes de ejecutar un script, revisa su origen, los permisos que solicita y las reglas de Roblox aplicables al uso previsto. Los archivos de este repositorio no deben tratarse como código confiable por el solo hecho de estar versionados.
